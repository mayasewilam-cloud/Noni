Photos for the scrapbook go here!

You can drop your real photos into this folder:
- memory1.jpg (Cinema memories)
- memory2.jpg (Coffee and chats)
- memory3.jpg (Best friends duo)
- memory4.jpg (Adventures)

Or add any photo filenames you want and update them in `config.js`!
If any photo is missing, the website displays a cute fallback card automatically.
